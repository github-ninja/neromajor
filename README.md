# 🕵️ Нейромайор

Шуточный Telegram-бот, который с нескрываемым удовольствием следит за перепиской участников чата, штрафует их по статьям УК РФ и ведёт личное досье на каждого — исключительно в воспитательных целях, разумеется.

## Команды

| Команда | Описание |
|---|---|
| `/stats` | Сводный реестр нарушений с индексом патриотичности |
| `/case @username` | Досье нарушений гражданина (или ответом на его сообщение) |
| `/profile @username` | Психологический портрет в стиле аналитика КГБ (или ответом на сообщение) |
| `/summary [N]` | Саркастичный рапорт по последним N сообщениям (по умолчанию 100) |
| `/stats_reset` | Амнистия — очистка всех нарушений (только для администраторов) |

Кроме того, Майор отвечает на упоминания и ответы на свои сообщения, сам вклинивается в живые разговоры, раз в день пишет в активные чаты и откликается в гостевом режиме в чужих чатах.

Отвечая на обращения, Майор сразу показывает анимированное «Печатает...», которое затем заменяется ответом. Если основная модель молчит дольше `GEMINI_REPLY_HEDGE_AFTER`, параллельно спрашивается облегчённая, и в чат идёт тот ответ, что пришёл первым. Если ответ не уложился в `GEMINI_REPLY_DEADLINE` или ИИ недоступен, вместо него приходит заготовленная реплика, подобранная под причину: лимит, таймаут, отказ модели или технический сбой.

## Как считаются нарушения

Каждое сообщение проверяется ровно один раз. Фоновый аудит раз в `AUDIT_INTERVAL` минут отправляет в Gemini пачки непроверенных сообщений (по курсору `chats.audit_cursor`) и сохраняет найденные нарушения с привязкой к конкретному сообщению и его дате. Курсор сдвигается только вместе с сохранением результата, поэтому сбой или лимит API ничего не теряет — пачка просто будет проверена позже. Расход запросов ограничен `AUDIT_DAILY_REQUESTS` в сутки и `GEMINI_RPM` в минуту на модель, что укладывается в бесплатный тариф.

`/stats` при необходимости дотягивает аудит (не более `AUDIT_STATS_REQUESTS` запросов) и показывает, сколько сообщений ещё ждут проверки.

Подробнее о санкциях и индексе — [в этой статье](https://telegra.ph/Nejromajor--logika-podscheta-narushenij-02-27).

## Устройство

```
bot/
  __main__.py      запуск, сборка зависимостей, фоновые задачи
  config.py        настройки из окружения (см. .env.example)
  db/              пул asyncpg, версионированные SQL-миграции, Repository
  ai/              клиент Gemini, схемы структурированных ответов, промпты, «голос» Майора
  services/        аудит, индекс патриотичности, реплики Майора (планировщик)
  handlers/        роутеры aiogram; messages.py — последний, catch-all
tests/
```

Миграции применяются автоматически при старте (`schema_migrations`).

## Запуск

1. Создай `.env` на основе `.env.example`.
2. Собери образ и подними стек:
   ```bash
   docker build -t neuromajor:latest .
   docker compose up -d
   ```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Интеграционные тесты БД запускаются, если задан `TEST_DB_URL` на пустую базу:

```bash
docker run --rm -d -p 127.0.0.1:55432:5432 -e POSTGRES_PASSWORD=t postgres:16-alpine
TEST_DB_URL=postgresql://postgres:t@127.0.0.1:55432/postgres pytest
```
